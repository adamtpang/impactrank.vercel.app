# ImpactRank

Starter: official Next.js create-next-app App Router + Tailwind (MIT).
Source: https://github.com/vercel/next.js/tree/canary/packages/create-next-app/templates/app-tw

Data and scoring live in data/opportunities.ts. Keep sources, caveats, and score methodology explicit. Do not invent costs or current funding availability. Interest collection uses mailto drafts, not a backend. Public interest recipient is configured through NEXT_PUBLIC_INTEREST_EMAIL.

Use npm test, npm run lint, npm run typecheck, npm run format:check, and npm run build before pushing.
